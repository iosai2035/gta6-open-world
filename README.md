Solmar Bay — an original 3D open-world crime game for make.fun's "Make GTA 6" bounty, $1,666 in USDC. A sun-soaked coastal city to explore on foot and by car in full 3D: steal cars, lose the heat, run five jobs for Mama Rosa, and take on the Solmar Bay police. Built with Three.js (vendored under game/vendor/), no network — the whole game is static files under game/.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to drive and walk, E to enter or exit a car, F to punch, mouse to aim, click to fire, Space for the handbrake, P to pause, M to mute.
